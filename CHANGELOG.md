# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-04-23

### Added
- Initial public release
- Complete IT Ticketing System with backend (Node.js + Express) and frontend (React + Vite)
- PostgreSQL database with Prisma ORM
- JWT authentication with refresh token support
- Role-based access control (Admin, Agent, Customer)
- Ticket management system with categories, priorities, and statuses
- File attachment support for tickets
- Email notifications via SMTP
- Docker Compose setup for easy deployment
- Comprehensive Ubuntu LTS deployment guide
- Windows Server and XAMPP deployment options
- Nginx reverse proxy configuration
- Let's Encrypt SSL/TLS support
- PostgreSQL backup automation
- PM2 ecosystem configuration for production
- Professional documentation (README, CONTRIBUTING, CODE_OF_CONDUCT)
- MIT License

### Features
- Create, assign, and manage IT support tickets
- Track ticket status and priorities
- Attach files and documents to tickets
- Comment and collaborate on tickets
- View audit logs
- Export ticket reports
- Dashboard with ticket statistics
- Admin panel for user and category management
- Responsive web interface
- Rate limiting on authentication
- Input validation and SQL injection prevention

### Documentation
- Setup guide for local development
- Docker deployment instructions
- Ubuntu LTS production deployment
- Windows Server setup
- XAMPP integration guide
- API documentation
- Security best practices
